# ミュージックルーム（携帯版）

PC の「YouTube ダウンローダー」と同じ機能を携帯で使うための Web アプリ（PWA）です。**私的利用専用**。
曲のファイルは各端末の中だけに保存し、高評価・プレイリスト・再生履歴（振り返り）だけを Firebase で PC と同期します。

## 1. 全体の構成

| 役割 | 使ったもの | 中身 |
|---|---|---|
| アプリ本体 | GitHub Pages（`pennenn/music-room`） | HTML・JavaScript だけで作った PWA。曲は置かない |
| 曲の保存 | 端末の中（OPFS・IndexedDB） | アプリ専用の領域。ほかの端末やクラウドには送らない |
| 携帯でのダウンロード | Termux ＋ yt-dlp（`termux/ytdl_server.py`） | 携帯の中だけで動くサーバー（127.0.0.1）。アプリに渡したら一時ファイルを消す |
| バックグラウンド再生 | `<audio>` ＋ Media Session | 画面を消しても再生。ロック画面・通知から操作できる |
| 共有から追加 | Web Share Target | YouTube アプリの「共有」→「ミュージックルーム」で URL が入る |
| 同期 | Firebase Authentication（Google）＋ Firestore | 電験ルームと同じプロジェクト。`music/{uid}` に本人だけ読めるルールで保存 |
| PC との連携 | `link.html` | PC アプリがブラウザでこのページを開き、ログイン結果を PC の中（127.0.0.1）に渡す |

費用はすべて無料の範囲です（GitHub Pages、Firebase の無料プラン）。

### 同期するもの・しないもの

| 同期する | 同期しない |
|---|---|
| 曲の情報（タイトル・アーティスト・長さ）、高評価、ムード | 曲のファイル（音声）、アートワーク |
| プレイリスト（その端末に無い曲は「未保存」と表示） | 曲の解析結果（テンポなど。各端末で計算） |
| 再生履歴（振り返りは PC と携帯の合計） | テーマなどの設定 |

同じ YouTube 動画は、PC と携帯で同じ曲として扱います（ID が `yt-動画ID`）。

## 2. 公開の手順（最初に 1 回）

1. **GitHub**
   1. Public のリポジトリ `music-room` を作る（README は追加しない）。
   2. このフォルダ（`C:\Users\penen\Documents\music-room`）で次を実行する。
      ```
      git remote add origin https://github.com/pennenn/music-room.git
      git push -u origin main
      ```
   3. Settings → Pages で「main / (root)」を選んで公開する。`https://pennenn.github.io/music-room/` で開ければ OK。
2. **Firebase**（電験ルームのプロジェクト `denken-room-d1ed7` をそのまま使う）
   1. Firestore → ルール に `firestore.rules` の中身を貼って「公開」する（電験ルームのルールも含まれているので、そのまま置き換えてよい）。
   2. Google ログインと承認済みドメイン `pennenn.github.io` は電験ルームで設定済みなので、追加の作業はない。

## 3. 携帯（Android）の準備

1. **アプリを入れる**：Chrome で `https://pennenn.github.io/music-room/` を開き、メニュー →「アプリをインストール」。
2. **Termux を入れる**：F-Droid から Termux をインストールする（Google Play 版は古くて動かない）。
3. **ダウンロードサーバーを入れる**：Termux を開いて、次の 1 行を貼り付けて実行する（数分かかる）。
   ```
   curl -sL https://pennenn.github.io/music-room/termux/setup.sh | bash
   ```
4. **起動する**：Termux で `ytdl` と入力する。ダウンロードするときは Termux を開いたままにしておく（閉じても通知に残っていれば動いている）。
5. **ログイン**：アプリの「設定 → PC と同期 → Google でログイン」。
6. 初めてダウンロードするとき「このサイトに、この端末上の他のアプリやサービスへのアクセスを許可しますか」と出たら **許可** する（Termux のサーバーに接続するため）。

### おすすめの設定

- 設定 → アプリ → Termux → バッテリー →「制限なし」（ダウンロード中に止まらないように）
- 画面を消すと再生が止まる場合は、Chrome も同じく「制限なし」にする
- Termux:Widget を入れると、ホーム画面から 1 タップでサーバーを起動できる（ショートカットは setup.sh が作成済み）

## 4. PC との連携

PC アプリの「設定 → 携帯と同期 → Google でログイン」を押すとブラウザが開くので、携帯と同じ Google アカウントでログインする。
以後は 3 分ごと・変更のたびに自動で同期する。

## 5. 使い方

- **ダウンロード**：右下のボタン → URL を入れて「ダウンロード」。YouTube アプリの「共有」から送ると自動で始まる。
- **端末の曲を取り込む**：ライブラリ右上のボタン、またはダウンロード画面の「ファイルを選ぶ」。
- **再生**：曲をタップ。下のバーをタップすると再生画面。ロック画面・通知からも操作できる。
- **プレイリスト**：曲の ⋯ →「プレイリストに追加」。プレイリスト画面の ⋯ で並べ替え・名前変更・削除。
- **おすすめ**：あなたへのミックス、ムード別ラジオ（集中・作業用 / ワークアウト / リラックス / 通勤・通学）。
- **振り返り**：年ごとの再生時間・よく聴いた曲・トップアーティストなど（PC と携帯の合計）。

## 6. つまずきやすいところ

- **「未接続」と出る**：Termux で `ytdl` が動いていない。Termux を開いて `ytdl` を実行する。
- **ダウンロードが失敗する**：「設定 → yt-dlp を更新」か、Termux で `ytdl-update` を実行してから `ytdl` で起動し直す。
- **同期で「権限がありません」**：Firestore のルールに `music` の部分が入っていない。手順 2 をやり直す。
- **PC の同期で「有効期限が切れました」**：PC アプリでもう一度「Google でログイン」する。

## 7. 更新するとき

- **アプリを直すとき**：このフォルダのファイルを直して commit → push。1 分ほどで公開ページに反映される。
  画面が古いままなら、`sw.js` の `CACHE` の番号を上げる。
- **ダウンロードサーバーを直すとき**：`termux/ytdl_server.py` を直して push し、携帯の Termux で `ytdl-update`。

## ファイル

|---|---|
| `index.html` | 画面の枠とデザイン（ライト / Dim / Lights Out） |

| `js/cloud.js` | Firebase 同期 |

| `termux/` | ダウンロードサーバーと初期設定スクリプト |
| `firestore.rules` | Firestore のルール（電験ルーム＋ミュージックルーム） |
